# 0.5.6 文本卡片显示修复

问题：多行文本的首行少于 70 个字符时会被当作标题。卡片标题固定限制为 52px，紧凑模式为 43px；中文首行超过两行后被裁切，而正文已经跳过整个首行，所以卡片下方即使留有空间，被裁掉的字也不会再出现。

修复：区分自动识别首行与手动名称。自动首行取消单独的高度限制，由整个卡片内容区域处理溢出；手动名称采用两行省略号。空白首行保持原文排版，避免首个非空行重复。

验证：增加真实 Electron 布局回归，用合成中文长首行和末尾换行复现用户截图。旧代码的字形底部超出标题框约 61px，新增检查失败；修复后紧凑和普通布局均通过。检查直接测量字形、标题框和卡片内容边界，并覆盖手动名称两行省略及开头空行的正文完整性。验证截图保存在本地 artifacts/ 或便携版 test-artifacts/，使用合成文字。

验证结果（2026-10-20）：47 项单元测试通过；0.5.6 原生助手构建、便携版打包与打包版完整 smoke 通过。新增报告字段 unclippedTextFirstLine、customTitleClamp、leadingBlankTextPreview 均为 true。打包版截图见 test-artifacts/text-card-compact.png 与 test-artifacts/text-card-normal.png。

本轮改动已按用户授权提交并发布至 GitHub。卡片用于内容预览，超过卡片物理高度的长文本仍会在底部渐隐，可按 Space 阅读完整内容；剪贴板中保存的原文不受布局修复影响。
