# 0.5.4 本地图片导入与交互优化

验证日期：2026-10-20。

本次实现：主动导入单张 PNG/JPEG 图片、按文件名搜索、重复图片合并、撤销导入、容量或保存失败时回滚。手动导入不依赖自动采集开关。解码前检查文件字节数、格式及像素上限，避免压缩文件尺寸小但解码像素异常大的输入直接进入原生解码器。

自动粘贴失败的恢复分支不再调用窗口 show/focus。用户已切换到其他应用时收起面板；保留错误供下一次呼出查看。成功粘贴后清除旧错误。这是失败恢复的交互修正，不代表目标窗口粘贴已完成端到端验收。

验证结果：

- 单元测试 46/46 通过。新增覆盖 PNG 与基线/渐进 JPEG 文件头、截断或伪装格式、文件大小与像素上限、解码失败、重复图片的元数据保留、撤销保留后来复制的内容、写盘失败和 2000 条全部固定时的完整回滚。
- 最初沙箱测试中两项已有的临时文件 rename 用例出现 EPERM；在正常 Windows 权限下重跑全量测试通过。
- 开发版桌面 smoke 通过，使用隔离目录和合成 PNG/JPEG：文件读取、后台编码、加密存储、按文件名搜索、图片预览、复制请求路由、Ctrl+Z 撤销，以及 Ctrl+O 取消导入均通过。
- 原有界面工作流、图片旋转、原生助手重连、隐藏面板更新、1852 条记录的虚拟滚动继续通过。smoke 的复制请求使用模拟路由，不向用户剪贴板写入数据；pasteDelivered=false。
- 原生 Windows 助手编译、0.5.4 x64 便携版打包通过。
- 打包后的 0.5.4 再次通过完整 smoke，确认新增模块随包分发；图片导入、搜索、预览、复制请求、撤销和取消均通过。

待人工确认：Windows 原生文件选择器的实际选取流程，以及用户切换应用时粘贴失败不会夺回焦点。在记事本或编辑器中确认 Enter、双击和顺序粘贴回原光标位置；自动化桌面此前无法激活受控接收窗口，此限制本轮未重新运行或认定解决。0.5.4 不作为已完成真实粘贴验收的正式二进制 Release 发布。
