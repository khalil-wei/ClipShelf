# ClipShelf 0.4 本地功能与验证

日期：2026-10-19。使用独立实现继续完善 Windows 本地剪贴板功能。

## 图片采集与粘贴

此前 0.3 的测试手动构造图片并写入历史，只证明预览、加密及请求路由，不证明外部图片能够自动被采集。用户报告 Windows 截图工具或微信截图未记入历史，因此本版新增真实 Windows 剪贴板验证。

修复了按 MIME 名称决定是否读图的限制，改为直接尝试读取 Windows 位图。事件后在 40/160/450ms 读取，750ms 检查系统序列号兜底。读取前后核对序列号，防止内容与来源在中途变化；存储失败不提前消耗去重签名。启动时采集当前内容。开启图片记录时也会重新尝试读取当前图片。

图片回写后会等待原生 Windows 读取端能够读取，随后才发送粘贴按键。回写过程暂停采集，避免自己的复制污染历史。另支持单个本地 PNG/JPEG 文件的剪贴板文件列表：读为图片进入历史，输出为位图；这不等于通用文件剪贴板支持。

集成验证由外部 Windows Forms STA 进程真实写入 96×64 位图，应用经剪贴板事件自动采集、加密、预览，再复制回系统，由独立原生接收端核对尺寸和像素。另写入 80×48 PNG 的文件列表并验证自动采集及图片输出。原剪贴板格式在内存保存，无中途用户复制时恢复；无法完整保存时在写入前取消。结果保存为 `artifacts/clipboard-integration-v4.json`，打包版在程序旁 `test-artifacts/`。

该验证覆盖 Windows 原生位图和文件列表；未宣称实际操作过微信界面，也未枚举所有截图软件的专用格式。

## 开机自启动

设置内增加「登录 Windows 时启动」，默认关闭。开启使用固定可执行文件路径及 `--background` 参数，登录后驻留托盘；手动打开仍展示面板。便携版移动前应关闭原路径的自启动，再从新路径重新开启。

统一 Windows AppUserModelId 与启动项名称，并检查启动项是否被 Windows 禁用。Electron 的 `openAtLogin` 按 AppUserModelId 查找，`launchItems.args` 不完整体现开关参数，因此验证结合对应启动项、路径、启用状态及注册表命令行。相关行为参考 [Electron 42 Windows 实现](https://github.com/electron/electron/blob/v42.0.0/shell/browser/browser_win.cc)。

真实 Windows 集成验证用独立临时名称开启和关闭启动项，核对后台参数及窗口初始隐藏，最后移除临时项。没有注销当前用户，未执行实际登录重启。正常 ClipShelf 自启动开关由用户在设置中开启。

## 其他本地功能

- 顺序粘贴：Ctrl+Shift+S 将所选内容按当前显示顺序加入队列；可反转、复制下一项、清空。Ctrl+Alt+P 在目标窗口粘贴下一项；快捷键占用时可从面板操作。失败不前进，操作期间拒绝并发，已删除项会跳过。队列只保留当前会话。
- 分组排序：拖动分组标签排序，分组内拖动卡片排序。重新复制不会打乱手动组内排序，历史列表仍按复制顺序。
- 跳回历史：Ctrl+G 或右键「在历史中显示」，清除筛选并定位内容。
- 定时暂停：5 分钟、15 分钟、1 小时或手动恢复。截止时间持久化，到期恢复；恢复时不补录暂停期间留下的内容。

## 验证范围

25 项 Node 测试包含历史迁移、媒体完整性、隐私、无 MIME 名称的位图采集、队列成功/失败及并发、组内顺序持久化、自启动状态、定时暂停等。Electron 界面回归实际操作设置开关、队列、拖动排序、搜索定位及暂停菜单；保留原有编辑、多选、撤销、主题和 1,852 条历史虚拟化验证。

截图为合成数据，帧间隔只代表测试机器。仍未实现通用文件/PDF 预览、OCR、云同步、共享分组、智能推荐或本应用的 MCP 服务；没有 Mac 原版运行环境，未证明动画及执行逻辑与 Paste 完全一致。实际逆向证据仍见 `reverse-v0.3.md`。

## 最终打包结果

0.4.0 成品位于 `dist/v0.4/ClipShelf-win32-x64/ClipShelf.exe`，整个同名目录需要保留。最终成品三组检查全部通过：

- `--smoke`：新增本地交互全部通过；1,852 条历史渲染 10 个节点，44 帧采样 p95 7.3ms；本次受控接收窗口成功收到原生 Ctrl+V。
- `--clipboard-integration`：真实 Windows 位图采集、原生像素核对、图片预览、单个 PNG 文件采集与位图输出全部通过，原剪贴板已恢复。
- `--startup-integration`：实际注册与关闭临时启动项、后台参数和窗口初始隐藏全部通过。

成品内 ASAR 清单实际核对为 33 个条目，版本 0.4.0，排除了 reference、artifacts、test、docs 及 Paste 原始参考材料。成品报告副本为 `artifacts/verification-v4-packaged.json`、`artifacts/clipboard-integration-v4-packaged.json`，启动项检查日志为 `artifacts/packaged-v4-startup-integration.stdout.log`。
