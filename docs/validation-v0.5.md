# ClipShelf 0.5：稳定性、图片操作与后台处理

日期：2026-10-19。Windows 本机功能；兼容原有账户加密的历史及图片文件。

## 本轮完成

- Windows 助手异常退出、启动失败或命令超时后自动重连，连续启动失败会延长重试间隔。旧连接排队中的命令会失败，不会在新连接上重放粘贴操作。
- 配置应用排除后，无法识别来源的剪贴板内容不会入库，界面显示「来源未确认 · 保护中」。助手恢复后重试；暂停、隐私设置及连接状态改变会使正在处理的旧采集任务失效。
- PNG 编码、透明像素转换、旋转及历史 JSON 序列化在工作线程完成。大块位图尽可能转移所有权，减少跨线程复制。后台线程异常退出后重建，不重放已失败操作。
- 图片及历史文件异步读写，媒体清理异步执行。历史写入保持调用顺序，以临时文件原子替换；保存失败会延迟重试，退出前等待最后一次保存。加密格式仍使用 Electron safeStorage，账户加密步骤仍在主线程。
- 对已经成功处理的剪贴板序列号跳过重复编码，避免事件、重试和轮询反复编码同一张大图。
- 图片预览支持适应窗口、100%、1%–400% 缩放、Ctrl+滚轮缩放、拖动查看、左右旋转及撤销。旋转保留名称、来源、收藏与分组。另存为使用系统文件对话框导出 PNG。
- 单图从 8 MiB/1600 万像素提高到 16 MiB/3200 万像素。图片原始 PNG 总预算仍为 128 MiB，文本与 HTML 总预算为 64 MiB；优先保留固定内容。容量不足时明确提示，并在再次打开面板时显示错误。
- 打开设置时重新读取 Windows 自启动状态；系统禁用后不再继续显示启动时缓存的旧值。

## 已验证

29 项 Node 测试通过，包含：PNG 通道、透明度和旋转；异步写入顺序及失败后重试；后台线程重建；助手断开后的恢复及旧粘贴命令不重放；来源不明时的应用排除保护，以及原有历史、隐私、分组、队列和设置回归。

Electron 回归实际终止助手进程，等待新的进程就绪后继续操作。图片界面验证缩放、旋转、预览解码、撤销及另存为请求路由；原有多选、编辑、历史定位、分组排序和自启动开关均覆盖。另存为验证模拟文件对话框返回，不会擅自写入用户选择之外的路径；尚未自动操作真实系统另存为对话框。

透明度在 Electron 中额外核对：工作线程 PNG 编码与 Electron 原生 PNG 编码解码后产生相同像素。长截图样本为 2048×8192（16,777,216 像素），另保存约 4 MiB 中文文本；后台处理期间主线程心跳持续运行。该样本为低复杂度合成图，不代表高噪声照片或所有设备的性能。

真实 Windows 剪贴板集成验证包含：终止助手、在断开期间配置应用排除并确认未知来源未入库、恢复后采集真实位图、原生接收端核对回写像素、单张 PNG 文件列表采集与位图输出。原剪贴板在无用户中途复制时恢复。使用合成位图，不宣称已经实际操作微信界面。

自启动仍验证实际临时启动项注册、后台参数、移除及窗口初始隐藏；未注销用户进行真实登录重启。

## 性能与剩余边界

工作线程降低了 PNG 编码与历史序列化对主线程的阻塞。位图提取/缩放、账户加密、部分历史正文传输仍在主线程，尚未完全移出。开发版长截图压力样本约 0.55–0.70 秒完成，主线程最大心跳间隔约 52–62ms；不能据此声称全程无卡顿。

UI 滚动回归仍为 1,852 条主要由短文本构成的历史，约渲染 10 个节点。没有 Mac 原版运行环境，不声称与原版帧级效果一致。

仍待完善：本地 OCR、通用文件/PDF 预览、可编辑的完整队列列表、本地加密备份恢复、正文增量传输和更广泛的实际应用兼容性验证。便携版移动后仍需重新设置自启动路径。

## 成品与证据

程序：`dist/v0.5/ClipShelf-win32-x64/ClipShelf.exe`，同目录文件需完整保留。先退出托盘中的旧版，再启动新版。

打包版结果在程序旁 `test-artifacts/`；外部日志在 `artifacts/packaged-v5-*.log`。截图 `shelf-v5.png`、`shelf-v5-dark.png`、`image-tools-v5.png` 均使用合成数据。

技术依据：[Electron NativeImage](https://www.electronjs.org/docs/latest/api/native-image)、[Node zlib 输出大小限制](https://nodejs.org/api/zlib.html#class-options)。PNG 生成、后台任务与 Windows 适配代码均为本项目实现，不包含 Paste 原始资源。

## 最终成品结果

0.5.0 的最终便携版三组检查均通过：`--smoke`、`--clipboard-integration`、`--startup-integration`。真实剪贴板报告确认助手恢复、未知来源保护、位图及 PNG 文件采集、原生像素匹配和原剪贴板恢复。

本机最终样本：16,777,216 像素长截图及约 4 MiB 文本处理合计约 687ms，主线程心跳 38 次、最长间隔 67ms；短文本历史滚动的 44 帧采样 p95 7.2ms。前者包含同步位图提取、加密及测试中的图片解码，仍存在可见的优化空间。
