# 0.5.5 导入失败回滚修复

验证日期：2026-10-20。

审查发现：图片导入先修改内存历史，再异步保存。若保存期间用户打开设置，state 接口会把尚未提交的图片发送给界面；随后保存失败时，旧代码仅回滚内存并清理图片文件，没有通知界面，造成界面与实际历史不一致。

修复：导入失败处理先广播回滚后的历史，再异步清理失败导入的图片。保存重试机制、已有图片和上一次撤销所需的图片继续保留。

验证结果：

- 新回归用例先在旧代码上复现失败，再在修复后通过。测试加载真实主进程处理器、导入事务和界面状态接收器，以可控的保存失败及延迟媒体清理复现时序；确认界面在清理结束前恢复正确历史，失败导入的图片不再显示，已有图片与上一次撤销图片仍在保留集合中。
- 全量单元测试 47/47 通过。
- 原生 Windows 助手编译与 0.5.5 x64 便携版打包通过。
- 0.5.5 打包版完整 smoke 通过，图片导入、搜索、预览、撤销和原有界面工作流保持正常；使用模拟复制路由，pasteDelivered=false。

回归用例不启动 Electron，不读取用户历史、不访问用户剪贴板，也不注册系统快捷键。本轮修复针对保存失败后的状态一致性；此前真实目标窗口的粘贴验收状态保持不变。
